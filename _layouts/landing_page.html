About Me

Mengenal saya lebih dekat

Hi everyone! Saya Ade Arya Bimantara, seorang yang gemar Programming yang berdomisili di Kota Tangerang. Saya adalah salah satu lulusan S1 - Teknik Informatika dengan konsentrasi Software Engineering dari Universitas Raharja. Saya mulai menyukai Programming dari SMK yang berawal dari rasa penasaran dengan sistem operasi Linux dan Open Source, yang mana kita dapat mengubah sourcenya sesuka hati. Sejak itulah saya mulai menyukai semua hal yang berkaitan dengan Source Code dan mulai mempelajari Programming.

Apa yang saya pelajari?

Perjalanan Programming saya dimulai dari mempelajari Linux, Open Source, dan Shellscript karena linux dibangun salah satunya dengan shell dan untuk keperluan ricing linux jadi saya mempelajarinya. Lalu bahasa pemrograman yang saya pelajari adalah C++, kemudian saya menemukan Python yang katanya sourcenya lebih simple, sederhana, mudah dibaca dan dipahami. Lanjut saya belajar Object Oriented Programming, Library, dan Framework seperti Django sebagai framework untuk web backend dan Kivy yaitu library untuk membuat aplikasi desktop berbasis GUI. Saya juga mempelajari Version Control System yaitu Git dan Github untuk mengelola source, selain itu saya juga mempelajari Virtualization seperti Docker dengan memanfaatkan container untuk keperluan open source. Sampai dimana saya lebih fokus untuk mempelajari terkait Web Development seperti HTML, CSS, Javascript dan PHP. Setelah itu saya mempelajari beberapa framework dan database management system seperti NodeJS, Laravel, VueJS, Mysql, MariaDB, Bootstrap dan TailwindCSS. Saat dikampus saya juga mempelajari Java, Assembler dan Visual Basic.
